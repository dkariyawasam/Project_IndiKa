# Roserade and Alolan sprite completion

Imported Roserade and the 18 official Alolan forms from [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion/tree/803bcb7c58afe73b0831893f383e6ce07fe0bac2/graphics/pokemon), pinned at 803bcb7c58afe73b0831893f383e6ce07fe0bac2. Upstream credits are retained in upstream-credits.md; source images and palettes are archived under source/. These are community GBA adaptations, not a claim of official FRLG sprites for later-generation forms.

Fronts use the first 64x64 animation frame. Backs remain native 64x64. Normal/shiny palettes retain upstream index correspondence. Menu icons preserve two frames, remapped to the closest of the three existing FRLG icon palettes. Coordinate bounds updated. Standard species footprints reused for corresponding Alolan forms, including intentionally blank prints for species without footprints. Existing Roserade footprint retained.

As explicitly requested, Alolan Pichu, Pikachu, Exeggcute and Cubone share their standard species' front/back, normal/shiny palettes, icons, footprints and coordinate metadata. No custom designs invented for these pre-evolutions. No overworld assets or Galarian forms were imported.

Preview sheets show normal front/back, shiny front/back and two icon frames. All 23 requested roster entries passed the active sprite audit, active Dex checks and main ROM build. No live emulator verification performed.
