# Regional pre-evolution poses

Alolan Pichu, Pikachu, Exeggcute and Cubone, and Galarian Koffing now use alternate front/back poses. Standard anatomy, normal/shiny palettes, icons and footprints are shared with their base species. The proposal's specific poses were used as a direction, not an exact redrawing specification: the selected classic alternate artwork shows a side-facing Pichu, outstretched Pikachu, rearranged eggs, shifted Cubone stance and a differently tilted Koffing.

Sources: [PokeAPI HGSS sprite archive](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/versions/generation-iv/heartgold-soulsilver), IDs172,25,102,104,109, front and back. Source artwork belongs to its original rights holders. Original downloads archived under source/. Images cropped to visible bounds, nearest-neighbour fitted where necessary, converted to existing FRLG palettes. Pichu back yellow shades mapped by shade role to avoid muddy nearest-colour conversion. Fronts centred; backs bottom-aligned in64x64. Coordinates updated.

comparison.png: standard front, alternate front, standard back, alternate back. Five complete asset sets and distinct sprite pixels verified; main ROM built. No live emulator verification performed. No other regional designs altered.
