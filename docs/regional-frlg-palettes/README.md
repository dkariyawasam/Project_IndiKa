# Regional FRLG palette alignment

Aligned all 18 implemented distinct Alolan forms' normal and shiny palettes to colours present in this project's first 151 Pokémon normal palettes. Each source shade maps to the closest available reference colour, retaining distinct shades and index correspondence. The changes are intentionally subtle; no geometry or dithering changed. Front/back embedded palettes updated; menu icons already use the shared FRLG icon palettes. The five standard-looking regional pre-evolutions already share their base species palettes and were not changed.

mapping.json records every old/new colour and reference species. before/ retains the original palettes and sprites. Comparison columns: old normal, new normal, old shiny, new shiny. All three sheets visually reviewed, pixel indices verified unchanged and main ROM rebuilt. Missing Galarian artwork remains a separate task.
