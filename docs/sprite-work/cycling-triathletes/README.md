# Cycling triathletes

Current sprites reuse the existing biker body, bicycle and ten animation frames, with heads transplanted from the original male and female cycling sheets. Each has a 16-colour palette. The wheel blue highlight is mapped to the metal grey to reserve hair colours.

The original character sheets are m-before.png and f-before.png. preview.png shows the current sprites. generated-reference.png is the rejected earlier concept and is not used by the game.

The three rear-facing frames now use the original triathletes’ purple athletic tops, including the female exposed waist.


## Female bicycle update — 13 October 2026

Updated all ten female bicycle frames using the user's current male cycling sheet. Female head, upper body and palette remain unchanged; side-view rider legs were retained. Male bicycle colours were mapped to the nearest existing female palette colours.

[Comparison](../../asset-previews/cycling-f-update.png): male reference, female before, female after. ROM build and packed-pixel checks passed; live animation review is pending.
