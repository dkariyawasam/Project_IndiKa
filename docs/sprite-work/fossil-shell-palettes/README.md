# Helix shell palette consistency

Omanyte and Omastar share normal shell palette entries 7–11. Copied that exact five-shade ramp in reverse order into Omato and Omatops normal entries 10–14. All other palette entries and every sprite pixel index remain unchanged. Updated embedded PNG palettes to reflect runtime colours. Main ROM build passed.

Back images contain different brown-shell artwork and do not use this cream ramp for their shell; that asset mismatch remains unresolved. Shared highlight entries also affect highlights elsewhere. Shiny palettes and menu icons were not modified.
