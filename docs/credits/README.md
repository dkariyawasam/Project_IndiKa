# Expedition Kanto credits

## Current implementation

The credits opening offers A for Expedition Kanto and SELECT for the complete original FireRed credits. It waits for an explicit selection. The fifteen project pages use existing scrolling Kanto maps, followed by the existing copyright and end screens. The 42 original attribution pages and their script remain intact.

Current pages: project title; game/art direction (Dee Kariyawasam); assistant director (Jake Moses); QA tester (Hongmiao Shi); editor (Hongmiao Shi); writing/story and programming (Dee Kariyawasam); original Pokémon designs (Dee Kariyawasam); pret decompilation; RHH sprite resources; PokeAPI archive; development tools; original game; original music/sound; thanks.
