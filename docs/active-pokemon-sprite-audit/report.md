# Active Pokémon sprite audit

404 active species checked. Retired/reserved IDs excluded. Checks compiled-table references, source existence, blank images, palette size and sprite dimensions. This is an asset audit, not a visual or live-game quality certification. Shiny graphics share battle sprites and use separate palettes. Overworld sprites are not required for every species. Blank footprint images can be intentional for species without footprints and are not treated as missing.
