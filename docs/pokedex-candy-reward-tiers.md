# Live Pokédex candy rewards

Live rewards enabled. Each ordinary page grants one candy of its assigned size plus one Rare Candy. Apex pages grant **2 Exp. Candy L + 1 Rare Candy**. Each completed habitat grants one Exp. Candy XL.

| Size | EXP |
|---|---:|
| S | 800 |
| M | 3,000 |
| L | 10,000 |
| XL | 30,000 |

S: straightforward collection and ordinary level evolutions. M: evolution items, branching requirements or longer training. L: any friendship evolution (including day/night and move-type conditions), Apex, legendary, fossil reconstruction, trade requirements or very high levels. These are live tiers; the encounter-rarity/progression audit is still incomplete. Pages without any direct wild encounter are explicitly flagged for acquisition review; habitat completion must not require unobtainable species.

## Implementation status

The four candy items are implemented using the existing candy Bag icon. Existing item IDs and save layout remain unchanged. They are usable outside battle, reject Eggs and level-100 Pokémon, cap EXP at level 100, and offer moves from every crossed level before checking evolution. Page and habitat reward claims are live. Earlier page claims stay claimed; no retroactive second reward. Habitat claims have separate saved flags.

Live counts: 2 × L: 9, L: 31, M: 76, S: 65.
