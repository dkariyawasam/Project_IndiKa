# Aeropteryx front sprite draft

Direct conversion of Dee Kariyawasam’s supplied artwork, with background removal, a 15-colour opaque palette plus transparency, and pixel adjustments to clarify the eye, mouth and horn accents. No generated artwork used.

front.png is a 64×64 indexed sprite. normal.pal is its matching JASC palette. front-preview.png is an 8× nearest-neighbour preview. This draft is not installed in the ROM.
