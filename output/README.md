# Retained artwork and review archive

These files preserve design history and source material. Installed game assets live in `graphics/`; files here should not be treated as the current game artwork or packaged as a player release.

- `aeropteryx/`: supplied artwork, sprite drafts, palette revisions and comparisons.
- `kabustar/`, `kabuknight/`: earlier sprites and palettes retained for comparison or recovery.
- `fossil-concept-refinement/`: generated concept refinements and earlier sprite versions.
- `imagegen/`: generation prompts and source images, including custom key-item and menu-icon artwork referenced by development notes.
- `map-and-dialogue-review/`, `pokedex-grid/`: historical UI and map captures; they may differ from the current build.

Keep original artwork, palette backups and provenance together. New routine build output belongs in ignored build directories, and release packages belong in `dist/`.
