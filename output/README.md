- `kabustar/`, `kabuknight/`: earlier sprites and palettes retained for comparison or recovery.
- Former `fossil-concept-refinement/`: archived outside this repository on 1 November 2026.
- Former `imagegen/`: archived outside this repository on 1 November 2026.
- `map-and-dialogue-review/`, `pokedex-grid/`: historical UI and map captures; they may differ from the current build.
