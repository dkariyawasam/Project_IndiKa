# Leafeon sprite import

Battle art: HeartGold/SoulSilver archived by [PokeAPI/sprites](https://github.com/PokeAPI/sprites/tree/master/sprites/pokemon/versions/generation-iv/heartgold-soulsilver), files `470.png`, `back/470.png`, `shiny/470.png`, `back/shiny/470.png`. Original Pokémon artwork belongs to its rights holders.

Icon, footprint and overworld assets: [pokeemerald-expansion](https://github.com/rh-hideout/pokeemerald-expansion/tree/master/graphics/pokemon/leafeon). Community-maintained GBA assets; precise original overworld game/artist provenance not independently established. Originals retained in `source/`.

Front 50×50 unchanged; back 54×77 reduced to 45×64. Nearest-neighbour scaling, 64×64 battle canvases and 16-colour normal/shiny palettes. Scaled back views received one-pixel outline repairs. Colours taken from existing FRLG Eevee, Gardevoir, Venusaur, Bellsprout, Glalie, Lapras and Chimecho palettes.

Two-frame menu icon and footprint wired. Overworld frames adapted and registered with matching normal colours; no NPC map placement added. Original shiny overworld palette retained for future use. Shared adaptation scripts are under `docs/leafeon-sprites/`.

Main ROM build and asset checks passed. Live battle/map testing remains outstanding.


Update: the unused overworld sheet, palette and graphics registration were removed at user request. Archived source references remain in this documentation directory. Battle sprites, palettes, footprints and menu icons remain installed.
